## 🔭 نظرة عامة

**BlackRock Ultra Screener** هو نظام متكامل لفرز الأسهم، مصمم للتحليل الكمي على مستوى مؤسسي. يجمع بين:

- **تحليل متعدد العوامل** مستوحى من نموذج BlackRock/Aladdin (6 عوامل)
- **تعلم الآلة المتقدم** مع مجموعة مكونة من 13 نموذجًا (XGBoost، LightGBM، CatBoost، MLP، Random Forest، وغيرها)
- **التعلم المعزز** عبر خوارزمية PPO (Proximal Policy Optimization) — مجموعة من 3 وكلاء
- **إدارة مخاطر احترافية** (معيار كيلي، القيمة في خطر VaR، مونتي كارلو، اختبارات الإجهاد)
- **آفاق زمنية متكيفة**: تداول فائق السرعة ← يومي ← أسبوعي ← مراكز ← مستثمر (سنة واحدة)
- **روبوت تيليغرام** لتقارير يومية آلية
- **واجهة مستخدم رسومية** متكاملة (Tkinter) مع لوحة تحكم للمخاطر

**تغطية الأسواق**: NASDAQ 100، S&P 500، PEA أوروبا (+200 سهم)، الشركات الصغيرة والمتوسطة، السلع، العملات الرقمية، الألعاب

## ✨ الميزات

### 🧠 التحليل الكمي
- **نموذج BlackRock متعدد العوامل**: Beta السوق، الحجم، القيمة، الزخم، الجودة، التقلب
- **أس هيرست (Hurst Exponent)** — الكشف عن الاتجاه / الانعكاس للمتوسط
- **البُعد الكسوري (Fractal Dimension)** — تعقيد السلسلة الزمنية
- **إنتروبيا شانون (Shannon Entropy)** — قياس حالة عدم اليقين في السوق
- **كشف التغيير في الأنظمة (CUSUM Regime Detection)**
- **معاملات Omega وSortino وCalmar والمعلومات**

### 🤖 تعلم الآلة
- **13 نموذجًا في مجموعة**: XGBoost، LightGBM، CatBoost، MLP، Random Forest، Extra Trees، Gradient Boosting، AdaBoost، Bagging، Logistic Regression، Ridge، KNN، SVC
- **تسمية Triple Barrier** (طريقة لوبيز دي برادو)
- **التحقق المتقاطع Purged K-Fold** — لا تسرب في البيانات
- **Meta-Labeling و Stacking**
- **أكثر من 150 ميزة كمية**
- **تخزين مؤقت ذكي** مع إلغاء صلاحية بحسب الأفق الزمني

### 🎮 التعلم المعزز (PPO)
- **3 وكلاء PPO في مجموعة** (تصويت بالأغلبية)
- **بيئة Gymnasium مخصصة** مع أكثر من 35 ملاحظة
- **آفاق زمنية متكيفة**: يضبط PPO نفسه وفق الملف (سرعة فائقة ← مستثمر)
- **مكافآت معايرة**: قائمة على Sharpe، معدّلة للمخاطر

### 📰 الأخبار والأرباح
- جمع بيانات متعدد المصادر (Google News، Yahoo Finance، RSS)
- تحليل المشاعر (أكثر من 200 كلمة مفتاحية موزونة)
- تتبع الأرباح (مفاجأة EPS، مفاجأة الإيرادات)
- تسجيل تأثير مدمج في النقاط النهائية

### 📊 الارتباطات متعددة الأصول
- مصفوفة ارتباط ديناميكية (متدحرجة 60 يومًا)
- الارتباط مع: VIX، SPY، TNX (معدلات الفائدة)، DXY (الدولار)، الذهب
- عوائد معدّلة بالبيتا وتوليد ألفا

### 🛡️ إدارة المخاطر (14 طريقة)
- **معيار كيلي (Kelly Criterion)** — تحديد الحجم الأمثل للمراكز
- **القيمة في خطر (VaR)** (تاريخية + مونتي كارلو 10,000 محاكاة)
- **اختبارات الإجهاد** (انهيار -30%، تصحيح -15%، ارتفاع المعدلات +200bp، وغيرها)
- **تتبع R-Multiples**
- **التوقعات ومعامل الميزة (Expectancy & Edge Ratio)**
- **ارتباط المحفظة** ومخاطر التركز
- **نقاط المخاطر المركبة (Risk Score Composite)** (0-100)

### 🤖 روبوت تيليغرام
- تقرير يومي تلقائي (قابل للتهيئة)
- أفضل 10 أسهم لكل أفق زمني: مستثمر، سرعة فائقة، أسبوعي
- أوامر `/rapport`، `/investisseur`، `/scalp`، `/swing`
- اكتشاف تلقائي لـ Chat ID عبر `/start`

## 📉 الاختبار الخلفي (Backtesting)

وحدة اختبار خلفي لاختبار الاستراتيجيات على البيانات التاريخية.

### الاستخدام عبر سطر الأوامر

```bash
# اختبار خلفي لـ SMA Crossover على AAPL (سنتان)
python backtester.py AAPL -s sma_crossover -p 2y

# اختبار خلفي لـ RSI على SPY (5 سنوات) برأس مال 50,000 دولار
python backtester.py SPY -s rsi_oversold -p 5y -c 50000
```

### الاستخدام عبر Python

```python
from backtester import Backtester

bt = Backtester(initial_capital=10000)
results = bt.run("NVDA", strategy="momentum", period="2y")
print(bt.report())

# الوصول إلى المقاييس
print(f"Sharpe: {results.sharpe_ratio:.2f}")
print(f"Max DD: {results.max_drawdown_pct:.1f}%")
```

### الاستراتيجيات المتاحة

| الاستراتيجية | الوصف |
|-------------|-------|
| `buy_hold` | شراء والاحتفاظ البسيط |
| `sma_crossover` | تقاطع SMA 20/50 |
| `rsi_oversold` | شراء عند RSI < 30، بيع عند RSI > 70 |
| `macd_signal` | إشارة MACD |
| `momentum` | ROC إيجابي لـ 20 يومًا |
| `mean_reversion` | نطاقات بولينجر (Bollinger Bands) |

## 🛡️ إدارة المخاطر

وحدة `RiskManager` تدمج 14 طريقة لإدارة المخاطر:

### مستوى المركز (Position Level)
- **معيار كيلي** — تحديد الحجم الأمثل بناءً على نسبة الفوز ونسبة الأرباح/الخسائر
- **القيمة في خطر التاريخية** — VaR عند مستوى الثقة القابل للتهيئة
- **القيمة في خطر مونتي كارلو** — 10,000 محاكاة لتقدير توزيع الخسائر
- **تتبع R-Multiples** — تتبع المخاطر بوحدات R

### مستوى المحفظة (Portfolio Level)
- **ارتباط المحفظة** — مصفوفة الارتباط للمراكز
- **مخاطر التركز** — مؤشر HHI (Herfindahl–Hirschman Index)
- **اختبارات الإجهاد** — 5 سيناريوهات (انهيار، تصحيح، معدلات، ركود، تداعي سريع)
- **نقاط المخاطر المركبة** — نقاط 0-100 مجمّعة متعددة المعايير

### المقاييس المعروضة
- التوقعات ومعامل الميزة
- الحد الأقصى للتراجع المُقدَّر
- VaR يومي وخماسي
- تأثير الإجهاد لكل سيناريو
- نقاط المخاطر الإجمالية

## 🔒 الأمان

> **لا تُدرج أبدًا بيانات حساسة في الكود** (رموز، مفاتيح API، بيانات اعتماد).

يستثني ملف `.gitignore` تلقائيًا:
- الرموز وملفات التهيئة الحساسة
- نماذج ML/PPO المُدرَّبة مسبقًا (كبيرة الحجم)
- ملفات التخزين المؤقت والسجلات
- ملفات البيئة

لروبوت تيليغرام، استخدم **متغير بيئة**:

```python
import os
BOT_TOKEN = os.environ.get("TELEGRAM_BOT_TOKEN", "")
```

## 🐳 Docker

انشر بسهولة باستخدام Docker.

### البناء والتشغيل

```bash
# بناء الصورة
docker build -t screener .

# تشغيل روبوت تيليغرام
docker run -d --name screener-bot \
  -e TELEGRAM_BOT_TOKEN=رمزك \
  screener

# تشغيل تحليل لمرة واحدة
docker run --rm screener python -c "
from stock_screener_ultra_v10 import Config, MoteurAnalyse
config = Config.charger()
config.appliquer_profil('INVESTISSEUR_1AN')
moteur = MoteurAnalyse(config)
for r in moteur.executer()[:10]:
    print(f\"{r['symbole']} - Score: {r['score_final']:.0f}\")
"
```

### Docker Compose

```bash
# تشغيل الروبوت على مدار الساعة
docker-compose up -d bot

# تشغيل تحليل يدوي
docker-compose run --rm screener
```
